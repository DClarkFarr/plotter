# Implementation Plan: Import Preview UI

**Branch**: `039-import-preview-ui` | **Date**: 2026-04-12 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/039-import-preview-ui/spec.md`

## Summary

Replace the placeholder preview summary in `ImportOutlineModal` with a three-tab interactive UI (Characters, Elements, Tags & Plots). Extend the `create` request to carry a structured `ImportCustomizations` JSON payload. On the backend, apply the customizations — skipping ignored characters, remapping merged aliases, and creating Plot documents for tags designated as plots rather than Tag documents with scenes assigned to those plots accordingly.

## Technical Context

**Language/Version**: TypeScript 5 (Node.js backend, React 18 frontend)  
**Primary Dependencies**: Express + Multer (backend); Flowbite React Tabs, TanStack Query, Zustand, Tailwind CSS, unplugin-icons (frontend)  
**Storage**: MongoDB  
**Testing**: Manual QA  
**Target Platform**: Web (Vite + modern browsers) + Node.js API  
**Project Type**: Web application (frontend + backend)  
**Performance Goals**: Preview tabs render within 2 seconds of parse response; API response under 200ms for normal load  
**Constraints**: No new third-party UI libraries; customizations must be applied entirely during create phase, not preview  
**Scale/Scope**: Single modal flow; outlines up to 100+ scenes

## Implementation Approach

### Backend

#### 1. `express/src/types/importOutline.ts`

Add the `ImportCustomizations` type:

```ts
export type ImportCustomizations = {
  ignoredCharacterIds: string[];
  characterMerges: Record<string, string>; // fromId → toId
  plotTagIds: string[];
};
```

#### 2. `express/src/routers/importRouter.ts`

In the `POST /outline` handler, after parsing `mode` and `storyName`, parse the optional `customizations` field:

```ts
let customizations: ImportCustomizations | null = null;
const rawCustomizations = req.body?.customizations;
if (rawCustomizations) {
  try {
    customizations = JSON.parse(rawCustomizations);
  } catch {
    throw new ValidationError(
      "customizations",
      "customizations must be valid JSON",
    );
  }
}
```

Pass `customizations` into `importOutlineForStory`.

#### 3. `express/src/services/importOutlineService.ts`

Add `customizations: ImportCustomizations | null` to `ImportOutlinePayload`.

In the `create` branch, apply all three customization types before (and during) the DB write phase:

**Characters (before creation loop):**

```
skipIds = new Set([
  ...ignoredCharacterIds,
  ...Object.keys(characterMerges)
])
```

Only create DB characters for characters NOT in `skipIds`. After the loop, add merge remappings:

```
for (const [fromId, toId] of Object.entries(characterMerges)) {
  const target = charIdMap.get(toId);
  if (target) charIdMap.set(fromId, target);
}
```

**Tags vs plots (before tag creation loop):**

1. Resolve eligible plot tag IDs: filter `plotTagIds` to only those that reference tags with `variant == null` in `parsed.tags`. Log a warning issue for any that have variants.
2. Group eligible plot tags by their `name`; for each unique name call `createPlot({ title: name, color: "#6B7280", storyId: story._id, horizontalIndex: plotHorizontalIndex++ })`. (Start `plotHorizontalIndex` at 1 since the Main plot takes index 0.)
3. Register in `plotMap: Map<string, ObjectId>` keyed by each parsed tag ID (same tag name may have multiple parsed IDs for different scenes).
4. Run the existing tag group loop, but skip any parsed tag IDs that are in `plotMap`.

**Scenes (during element loop):**

For each scene:

1. Separate its `tagIds` into `plotTagRefs` (IDs in `plotMap`) and `normalTagRefs` (rest).
2. Determine assigned `plotId`:
   - If `plotTagRefs.length === 1` → use `plotMap.get(plotTagRefs[0])`.
   - If `plotTagRefs.length > 1` → use first, append a warning issue.
   - If `plotTagRefs.length === 0` → use Main `plot._id`.
3. Build `tags` and `tagVariants` from `normalTagRefs` only (same logic as before).
4. Call `createScene({ plotId: resolvedPlotId, ... })`.

#### 6. `web/src/components/dashboard/ImportOutlinePreviewTabs.tsx` (new file)

A controlled component with three Flowbite `Tabs.Item` panes.

**Props:**

```ts
type ImportOutlinePreviewTabsProps = {
  characters: ParsedCharacter[];
  elements: ParsedElement[];
  tags: ParsedTag[];
  customizations: ImportCustomizations;
  onCustomizationChange: (next: ImportCustomizations) => void;
};
```

**Tab 1 — Characters:**

- `<ul>` of character rows.
- Each row: character name on the left; right-aligned group with Ignore checkbox and Merge With button.
- Ignore: `checked` when `id` is in `customizations.ignoredCharacterIds`; on change, toggle. Row gets `opacity-50 line-through` when ignored.
- Merge with: shown when not ignored. Clicking replaces the button with a `<select>` of all other non-ignored characters. Selecting sets `characterMerges[id] = selectedId`. A small clear icon resets it.

**Tab 2 — Elements:**

- Read-only nested list: acts → chapters → scenes.
- Acts: `text-base font-bold`.
- Chapters: `text-sm font-semibold pl-4`.
- Scenes: `text-sm pl-8`. Secondary line below scene title shows:
  - POV badge: small pill with character name (look up by `povCharacterId` from the `characters` prop).
  - Tag badges: one per tag ID (look up name from `tags` prop). Include variant label if present.

**Tab 3 — Tags:**

- Group tags by name. For each name group:
  - If all entries have a non-null variant → show tag name + "Tag only" label (no checkbox).
  - If any entry has `variant == null` → show "Convert to plot" checkbox. State keyed by the `id` of the null-variant entry. Checking adds that id to `plotTagIds`; unchecking removes it.
  - If a name group has mixed variant and null-variant entries, show the checkbox for the null-variant entry and the "Tag only" label for variant entries.

#### 7. `web/src/components/dashboard/ImportOutlineModal.tsx`

- Add state: `previewData: ImportOutlineResponse | null` (replaces the bare `previewSummary` in the preview step).
- Add state: `customizations: ImportCustomizations` initialised to `{ ignoredCharacterIds: [], characterMerges: {}, plotTagIds: [] }`.
- In `handlePreview`: store the full result in `previewData` (not just `result.summary`).
- In the `preview` step JSX: replace the placeholder `<div>` with `<ImportOutlinePreviewTabs ... />` plus the existing story name field above it.
- In `handleApprove`: pass `customizations` as `input.customizations` to `importMutation.mutateAsync`.
- Reset `customizations` to the empty object in `resetState`.
