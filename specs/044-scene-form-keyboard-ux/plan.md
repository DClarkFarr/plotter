# Implementation Plan: Scene Form Keyboard UX Improvements

**Branch**: `044-scene-form-keyboard-ux` | **Date**: 2026-04-17  
**Spec**: [spec.md](spec.md)

## Summary

Add three keyboard convenience interactions to `SceneForm`: Tab from the scene title input focuses the description TipTap editor body; Enter in the todo add-item input submits the item; Tab from a snippet title input focuses that snippet's TipTap editor body. All changes are confined to the frontend (`web/`). No server, database, or API changes are required.

## Technical Context

**Language/Version**: TypeScript 5.x  
**Primary Dependencies**: React 18, TipTap (`@tiptap/react`, `@tiptap/starter-kit`), dnd-kit  
**Storage**: N/A — no data model changes  
**Testing**: Manual (see quickstart.md)

**Project Type**: Web application

**Constraints**: No new libraries. No changes to existing Tab order for fields other than title → description and snippet title → snippet text.  
**Scale/Scope**: Three focused edits across two components + one shared component

## Phase 0: Research

✅ Complete — see [research.md](research.md)

Key decisions resolved:

| Unknown | Decision |
|---------|----------|
| How to focus TipTap from outside component | `forwardRef` + `useImperativeHandle` exposing `{ focus() }` on `RichTextEditor` |
| How to intercept Tab without breaking natural order | `preventDefault()` on forward Tab in `onKeyDown`; leave Shift+Tab to browser |
| Enter for todo | Reuse existing `handleAdd` in `onKeyDown` |
| Dynamic snippet list refs | `useRef<(RichTextEditorHandle \| null)[]>([])` indexed by snippet position |

### Implementation Design

#### 1. `RichTextEditor.tsx` — expose imperative focus handle

```tsx
export type RichTextEditorHandle = { focus: () => void };

export const RichTextEditor = forwardRef<RichTextEditorHandle, RichTextEditorProps>(
  ({ value, onChange, isSimpleMode = false }, ref) => {
    const editor = useEditor({ ... });

    useImperativeHandle(ref, () => ({
      focus: () => editor?.commands.focus('end'),
    }), [editor]);

    return (
      <div>
        {editor && <MenuBar editor={editor} isSimpleMode={isSimpleMode} />}
        <EditorContent editor={editor} />
      </div>
    );
  }
);
```

No changes to existing props or render output.

#### 2. `SceneTodoList.tsx` — Enter key on add-item input

Add `onKeyDown` to the existing `<input>`:

```tsx
onKeyDown={(event) => {
  if (event.key === 'Enter') {
    handleAdd();
  }
}}
```

No props changes. No render changes.

#### 3. `SceneForm.tsx` — wire refs and Tab handlers

**Title → Description (FR-001)**:
```tsx
const descriptionEditorRef = useRef<RichTextEditorHandle>(null);

// on title input:
onKeyDown={(event) => {
  if (event.key === 'Tab' && !event.shiftKey) {
    event.preventDefault();
    descriptionEditorRef.current?.focus();
  }
}}

// on description RichTextEditor:
<RichTextEditor ref={descriptionEditorRef} ... />
```

**Snippet title → Snippet editor — Add Snippet modal (FR-006)**:
```tsx
const newSnippetEditorRef = useRef<RichTextEditorHandle>(null);

// on newSnippetLabel input in modal:
onKeyDown={(event) => {
  if (event.key === 'Tab' && !event.shiftKey) {
    event.preventDefault();
    newSnippetEditorRef.current?.focus();
  }
}}

// on modal RichTextEditor:
<RichTextEditor ref={newSnippetEditorRef} ... />
```

**Snippet title → Snippet editor — inline expanded snippets (FR-008)**:
```tsx
const snippetEditorRefs = useRef<(RichTextEditorHandle | null)[]>([]);

// for each expanded snippet's title input:
onKeyDown={(event) => {
  if (event.key === 'Tab' && !event.shiftKey) {
    event.preventDefault();
    snippetEditorRefs.current[index]?.focus();
  }
}}

// for each expanded snippet's RichTextEditor:
<RichTextEditor
  ref={(el) => { snippetEditorRefs.current[index] = el; }}
  ...
/>
```
