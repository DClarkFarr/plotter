# Quickstart: Create Tag Form Reuse

## Prerequisites

- Install dependencies in `web/`.

## Run

1. Start the frontend dev server.
2. Open a story in the dashboard and navigate to the tag management view.
3. Create a new tag with a name and color.
4. Open a scene tagging modal and create another tag from the same form.

## Expected Result

- Newly created tags appear in their respective lists without a reload.
- Empty tag names are rejected with a clear error message.
