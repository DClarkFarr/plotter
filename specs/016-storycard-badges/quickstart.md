# Quickstart: Story Card Count Badges

## Prerequisites

- Node.js and npm installed
- MongoDB configured for the Express API
- Valid user session or auth cookie for API requests

## Run Locally

1. Start the API server:
   - `cd express`
   - `npm run dev`
2. Start the web app:
   - `cd web`
   - `npm run dev`
3. Open the dashboard in the browser and verify story cards show badges for plots, scenes, characters, and tags.

## Manual Verification

- Create or seed a story with characters and tags.
- Refresh the dashboard and confirm badge counts match the story data.
