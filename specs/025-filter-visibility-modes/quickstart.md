# Quickstart: Filter Visibility Modes

## Prerequisites

- Node.js and npm installed

## Run the web app

1. `cd web`
2. `npm install`
3. `npm run dev`

## Key locations

- Story top-bar controls and filters: `web/src/components/story`
- Plot grid rendering: `web/src/components/plot/PlotGrid.tsx`
- Scene cards: `web/src/components/plot/SceneRenderer`
- Story list view: `web/src/components/story`
