# Quickstart: Character Card

## Goal

Preview the CharacterCard and CharacterCardPopover flows from both entry points.

## Prerequisites

- Access to a story with at least one character
- Web app running locally

## Steps

1. Start the web app dev server.
2. Open a story scene and click the character display in a scene card to open the character card popover.
3. Click the character image to open the lightbox and then dismiss it.
4. Hover over the card, click the edit button, and upload a new image.
5. Open ManageCharactersPanel and click a character avatar to verify the same popover workflow.

## Expected Results

- Character card displays a large image, stylized name, and description.
- Clicking the image opens and dismisses the lightbox.
- Hovering reveals the edit button; uploading a new image updates the card and lightbox.
- ManageCharactersPanel no longer uses the old click-to-upload interaction.
