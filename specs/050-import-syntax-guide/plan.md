## Summary

Replace the minimal inline bullet-point instructions shown in the Import Outline modal when
"Modern outline" is selected with a rich `ModernImportInstructions` component. The component
mirrors the layout and style of the existing `LegacyImportInstructions` component — two-column
sections with a descriptive left panel and a dark example block on the right — covering all
seven constructs recognized by the modern outline parser: acts, chapters, scenes (with and
without POV), plots (H4 and pipe-prefix forms), tag rows, snippet headings, and snippet body
paragraphs.

No backend changes, no new dependencies, no API contract changes.

## Implementation Phases

### Phase A — Add `ModernImportInstructions` component

**File**: `web/src/components/dashboard/ImportOutlineModal.tsx`

#### A1 — Remove the existing inline modern instructions fragment

The current code that renders when `importType === "modern"` is a small `<>` fragment with
two `<div className="space-y-2">` sections (a heading-map bullet list and a tags/snippets
blurb). Remove this fragment entirely.

#### A2 — Add `ModernImportInstructions` as a named component

Add the component at the bottom of `ImportOutlineModal.tsx`, immediately before or after
`LegacyImportInstructions`. The component:

- Is a `const` arrow function returning JSX — same pattern as `LegacyImportInstructions`
- Takes no props
- Uses `<div className="text-sm text-slate-600">` as the root — same as legacy
- Uses the same two-column section layout: `<div className="lg:flex gap-6 mb-10 space-y-4">`
  with `<div className="lg:w-1/2">` for each column

#### A3 — Sections to implement

Each section follows the pattern: `<h1 className="text-xl text-slate-950">Title</h1>` +
a two-column div with description left and dark example block right.

**Section 1 — Document Structure**

Left:

- H1 headings become acts.
- H2 headings become chapters.
- H3 headings become scenes (the plot heading must appear directly before).

Right example block (dark `bg-slate-800 p-4 rounded-lg text-slate-200`):

```
(H1) Act 1 — Into the Storm

  (H2) Chapter 1 — Arrival

    | Main Journey

    (H3) Nick Fury: Scene opens at the facility
```

**Section 2 — Scene POV Character**

Left:

- The POV character is optional and placed at the start of the H3 scene heading.
- Syntax: `Character Name: Scene Title`
- Without a POV: just a bare scene title.

Right example:

```
(H3) Nick Fury: Investigates the Tesseract activity
(H3) The Tesseract activates on its own
```

**Section 3 — Plots**

Left:

- A plot heading must appear directly before its scene heading.
- Two equivalent forms are accepted:
  1. **Heading 4**: format the line as an H4 heading (with or without `|` prefix).
  2. **Pipe prefix**: any paragraph or heading whose text begins with `|`.
- Each scene belongs to exactly one plot; plots become rows in the story grid.
- Optional: the text color of the `|` character is captured as the plot's color on import.

Right example:

```
| Main Journey

(H3) Nick Fury: Investigates the Tesseract activity

(H4) | Villain Arc

(H3) Loki: Portals through the Tesseract
```

**Section 4 — Tags**

Left:

- The first non-empty paragraph immediately after a scene heading becomes the tag row.
- Basic tag syntax: `[TagName]`
- Variant tag syntax: `[TagName:Variant]`
- Multiple tags can appear on the same line separated by spaces.
- Optional: the text or highlight color of a `[Tag]` token is preserved as the tag's color on import.

Right examples — three separate dark blocks:

Block 1 (basic tag):

```
(H3) Nick Fury: Investigates the Tesseract activity
[Action]
```

Block 2 (variant tag):

```
(H3) Loki: Fights guards and steals the Tesseract
[Action:Victory]
```

Block 3 (multiple tags):

```
(H3) Gamora: Learns the truth about Thanos
[Suspense] [Plot Twist]
```

**Section 5 — Snippets**

Left:

- Paragraphs indented at least ~1 cm (≥ 600 twips in Word / LibreOffice) inside a scene
  become snippet content.
- To label a snippet, add a heading line before it using either:
  - **Heading 5**, or
  - Any indented paragraph whose text ends with `:` (e.g. `Draft:`)
- Paragraphs after a snippet heading that are also indented become the snippet body.
- Indented paragraphs without a preceding heading are grouped into an auto-labelled snippet.

Right example:

```
(H3) Nick Fury: Investigates the Tesseract activity
[Action]
Scene opens at the facility.

  (H5) Draft:
    Fury: You say peace, but I kind of think you mean the other thing.
    Loki: Do I make you desperate?
    Fury: You're making me very desperate.

Back to scene description.
```

#### A4 — Wire into `ImportOutlineModal`

Replace the existing inline fragment:

```tsx
{
  /* BEFORE */
}
{

    <LegacyImportInstructions />
  ) : (
    <>
      <div className="space-y-2">...</div>

    </>

```

With:

```tsx
{
  importType === "legacy" ? (
    <LegacyImportInstructions />
  ) : (
    <ModernImportInstructions />
  );
}
```
