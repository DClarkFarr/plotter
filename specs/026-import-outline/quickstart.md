# Quickstart: Import Outline Modal

## Goal

Verify the dashboard import modal, uploader, and preview stub.

## Steps

1. Start the backend and frontend (`npm run dev` in both `express/` and `web/`).
2. Navigate to the dashboard and click the import button next to the create story button.
3. Review the formatting instructions shown in the modal.
4. Upload a .docx file and submit the form.
5. Confirm the modal switches to preview mode and displays the TODO summary placeholder.
6. Try a non-.docx file and confirm the error message is shown.
